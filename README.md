# Yeshwanth Reddy — Portfolio

Personal portfolio with projects, a portrait, seven credentials, and React Bits and MotionFlow effects.

Run locally:

```sh
npm install
npm run build
python -m http.server 8000 --directory dist
```

Publish the `dist` directory on a static host. See `src/THIRD_PARTY_NOTICES.md` for third-party components.
