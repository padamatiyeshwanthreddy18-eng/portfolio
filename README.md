# Yeshwanth Reddy — Portfolio

Personal portfolio featuring projects, a portrait, seven credentials, and interactive React Bits and MotionFlow effects.

## Run locally

```sh
npm install
npm run build
python -m http.server 8000 --directory dist
```

Open http://localhost:8000.

## Deployment

Publish the `dist` directory on any static host.
